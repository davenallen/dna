  content: '
      <p><strong>Role:</strong> UX/UI design + front-end build</p>
      <p><strong>Context:</strong> Simpler Trading — product marketing for scanning tools and trading indicators</p>
      <h5>The decision</h5>
      <p>The page has to move a trader from the headline to a signup, with the proof, the features, and the button visible on the way down, on desktop and on a phone.</p>
      <h5>What I owned</h5>
      <ul>
        <li>The layout: a benefit-led hero, feature proof, capability cards, an FAQ, and a call to action that repeats down the page. The palette is deep navy and teal, with chart motifs kept quiet.</li>
        <li>The JavaScript and the WordPress build, so marketing can change the copy after launch.</li>
        <li>The release. Hierarchy and the button stayed intact across breakpoints, and the page went out as a campaign surface.</li>
      </ul>
      <h5>How someone else reuses it</h5>
      <p>The sections are a sequence marketing can refill. Swap the product. Keep the order: promise, proof, detail, objection, action. A new offer does not start from a blank page.</p>
      <h5 id="react">In React and Next.js</h5>
      <p>The same page is a route made of sections. Hero, proof, feature grid, FAQ, and the call to action are components that take the offer as data. The button is the shared button. Sass tokens carry the navy and the teal, so the next campaign changes the content and stays on the system.</p>
      <p><em>Skills demonstrated:</em> Landing page CRO, UX writing hierarchy, responsive UI, WordPress, JavaScript, marketing collaboration.</p>
    '
